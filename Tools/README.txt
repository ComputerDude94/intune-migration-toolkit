Copy these in by hand (they are not included in the toolkit):

  Profwiz.exe   ForensiT User Profile Wizard (freeware GUI)
  Profwiz.msi   Alternative: installer that just extracts Profwiz.exe
  MCPR.exe      McAfee Consumer Product Removal (optional)
  *.ppkg        Optional Windows provisioning package for a silent Entra join
                (build in Windows Configuration Designer with a bulk enrollment token)

Executables are signature-checked and hashed in the log before they run.
